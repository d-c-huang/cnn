# 知微 · 从零训练一个 AI

面向零基础的交互学习实验室。四期共 13 个实验，连接数据、前向计算、梯度、参数更新、真实数据集训练与模型推理；页面中的数值与图形由 FastAPI 调用 NumPy 和 PyTorch 实际计算。

当前交付包含基础交互实验、计算图、反向传播播放器、XOR 网络、MNIST 上 MLP/CNN 的后台训练与独立评估，以及加载最佳权重的手写识别、双模型对比和 Docker 部署配置。仓库自带第三期真实训练导出的模型包，第四期推理无需重新训练。

## 环境与启动

- Node.js 22.14 或更高版本。
- Python 3.11 或更高版本。
- 前两期不需要 GPU、预训练权重或外部数据下载；第三期需要 PyTorch、Torchvision，并在首次准备时联网下载官方 MNIST。
- 第四期复用同一 Python 环境，通过随仓库提供的 `models/` 权重与真实测试示例即可推理；安装依赖后，手写识别不需要下载完整 MNIST。
- CPU 版 PyTorch 即可。项目依赖要求 `torch>=2.7.1,<3.0`、`torchvision>=0.22.1,<1.0`，应使用相互兼容的组合；本机验证环境为 `torch 2.7.1+cpu` 与 `torchvision 0.22.1+cpu`。已有兼容环境无需为本项目升级全局包。

## 第一期：五组基础实验

| 实验 | 可以操作的内容 | 计算定义 |
| --- | --- | --- |
| 数据与张量 | 编辑教学像素，观察矩阵、展平向量及归一化 | 灰度值范围 0–255；归一化为 `pixel / 255`；按行展平 |
| 线性模型 | 调整权重和偏置，查看预测线与误差 | `ŷ = wx + b`，`MSE = mean((ŷ − y)²)` |
| 单个神经元 | 调整两个输入、权重、偏置与激活函数 | `z = x₁w₁ + x₂w₂ + b`，`output = activation(z)` |
| 损失函数 | 调整预测值和目标值，观察损失与导数 | 单样本平方损失 `L = (ŷ − y)²`，`dL/dŷ = 2(ŷ − y)` |
| 梯度下降 | 单步或连续更新权重，比较不同学习率 | 由五个样本计算全量梯度，`w_next = w − α × dL/dw` |

像素图是手工构造的教学样本，不属于 MNIST。线性实验与梯度下降共用五个教学样本：`x = [-2, -1, 0, 1, 2]`，标签为 `y = 2x + 0.5`，便于验证计算结果。

梯度下降实验固定偏置 `b = 0.5`，因此：

```text
L(w) = 2(w − 2)²
dL/dw = 4(w − 2)
w_next = w − α × 4(w − 2)
```

对这个特定目标函数，`0 < α < 0.5` 时收敛；`α = 0.5` 时，在非最优起点会等幅振荡；`α > 0.5` 时发散。这个稳定范围取决于当前函数，不适用于所有模型。每次更新使用全部五个样本，是一次全量梯度更新；当前页面不涉及完整训练平台中的 batch/epoch 调度。

梯度下降记录可导出 CSV，其中 `gradient_used_for_update` 是产生该行更新时使用的梯度，`weight_after_update` 和 `loss_after_update` 是更新后的状态；第 0 行为起始状态。

### 计算图与反向传播

本节把一个 tanh 神经元拆成以下运算：

```text
p₁ = x₁w₁
p₂ = x₂w₂
s = p₁ + p₂
z = s + b
a = tanh(z)
e = a − y
L = ½e²
```

这里的平方损失包含 `½`，因此 `∂L/∂e = e`；第一期损失实验使用 `L = (ŷ − y)²`，其导数为 `2(ŷ − y)`。两处系数不同是为方便逐步理解求导，不应混用。

节点的梯度是 `∂L/∂节点值`。每条边保存当前前向值处的局部导数；沿边反向传递时，用后续节点的梯度乘以该局部导数，多条后续路径的贡献相加。输入和标签也能求导，但本实验优化器只更新 `w₁、w₂、b`：`θ_new = θ_old − η × gradient`。界面将反向传播求梯度与 SGD 应用更新分开，更新后的损失必须用新参数再次前向计算。

### XOR 小型神经网络

固定教学数据为 `X = [[0,0], [0,1], [1,0], [1,1]]`、`y = [0,1,1,0]`。网络含两个输入、四个 tanh 隐藏单元、一个 sigmoid 输出，总计 17 个可训练权重和偏置：

```text
z₁ = XW₁ + b₁           W₁: [2,4], b₁: [4]
a₁ = tanh(z₁)
z₂ = a₁W₂ + b₂          W₂: [4],   b₂: 标量
p = sigmoid(z₂)
L = mean(logaddexp(0, z₂) − y × z₂)
```

BCE 从 logits 稳定计算，避免先裁剪概率再取对数造成损失与梯度不一致。每次 SGD 使用全部四个样本，输出层起始梯度为 `(p − y) / 4`。先使用同一组旧参数计算全部梯度，再同时更新所有参数。

默认随机种子 `7`、学习率 `1` 的实际 NumPy 运行结果：初始平均 BCE 约 `0.768087`；100 步后约 `0.0569704`；500 步后约 `0.00500017`，四个训练点均分类正确。这个结果衡量四个教学训练样本，不是独立测试集上的泛化能力，其他随机种子和学习率可能得到不同结果。

自动训练每次请求执行 20 步，曲线记录其中每一步更新后的真实损失和准确率。每批返回后，当四个训练点准确率为 `100%` 且平均 `BCE < 0.02` 时自动停止；总步数上限为 `5000`。停止后仍可单步更新，直至达到上限。手动暂停会允许正在进行的这一批请求完成。改变学习率会保留已提交的权重与曲线，重新初始化才会清空当前训练。

界面区分两个梯度时刻及两种样本范围：

- 网络中的“当前样本梯度”来自所选单个样本；“四样本平均梯度”才是 SGD 使用的全量梯度。
- 网络与当前梯度使用最近已提交的参数。参数更新表中的“使用的平均梯度”来自最后一次更新前，与该行更新前后参数一一对应。
- 选择其他观察样本会暂停训练并重新计算该样本的前向值和梯度，不更新模型参数。

预测网格由同一组参数计算，范围为 `[-0.25, 1.25] × [-0.25, 1.25]`，包含 `25×25` 个点。色块表示 sigmoid 输出，分类阈值为 `0.5`，不能直接视为经过校准的置信度。

XOR 可导出逐步历史 CSV，以及包含架构、随机种子、学习率和当前参数快照的 JSON。**当前仅支持导出，没有 JSON 导入功能。** XOR 后端接口无状态，当前 XOR 模型和训练历史保存在实验组件内存中；离开 XOR 实验或刷新页面后，会重新初始化。需要保留参数时应先导出。

### 三份数据的边界

官方 MNIST 包含 60,000 个训练样本和 10,000 个测试样本。第三期只从官方训练部分按类别分层随机划出验证集：

| 验证比例 | 可用训练集 | 验证集 | 官方独立测试集 |
| --- | ---: | ---: | ---: |
| 10%（默认） | 54,000 | 6,000 | 10,000 |
| 20% | 48,000 | 12,000 | 10,000 |

训练集与验证集互不重叠，同一随机种子生成可复现的划分。训练与验证索引属于官方训练文件，测试索引属于另一份官方测试文件；两者的索引都从 0 开始，不能仅凭索引数字判断是不是同一个样本。

`train_limit=null` 使用完整训练划分；快速实验可以从可用训练集再分层抽取 6,000 或 12,000 个样本。快速模式只减少**实际参与梯度更新**的数量，验证集和独立测试集仍使用完整规模。页面同时标注可用训练数量与实际使用数量，类别统计中的“实际训练”对应抽取后的数据。

原始图像为 28×28 单通道灰度数据，预处理统一为 `x = pixel / 255` 后再做 `(x − 0.1307) / 0.3081`。训练、验证和测试使用同一套固定预处理，标准化后的数值可以为负。MLP 在模型内部展平图像；CNN 保留空间结构做卷积。

### 两个真实 PyTorch 模型

- MLP：`Flatten → Linear(784,128) → ReLU → Linear(128,64) → ReLU → Linear(64,10)`。
- CNN：`Conv(1,8,3,padding=1) → ReLU → MaxPool(2) → Conv(8,16,3,padding=1) → ReLU → MaxPool(2) → Flatten → Linear(16×7×7,64) → ReLU → Linear(64,10)`。

两个模型均使用 Adam 和多分类交叉熵。训练输出是 logits，交叉熵内部处理相应变换；错例详情中的十类分数由测试 logits 经过 softmax 得到。训练实际执行 `zero_grad → forward → loss.backward → optimizer.step`，没有用浏览器动画或预录曲线代替训练。

训练指标是该轮真实训练批次的样本加权平均。每轮结束后将模型切换到评估模式，在完整验证集上计算指标，并按**最低验证损失**保存最佳权重。所有训练轮次结束后，再加载该最佳权重，对完整 10,000 张独立测试图像评估一次。测试集不参与参数更新、最佳轮次选择或每轮训练曲线。

默认训练配置为随机种子 `7`、3 个 epoch、batch size `128`、学习率 `0.001`、验证比例 `0.1` 和完整训练集。以下是该配置在真实官方 MNIST 上的已完成运行结果：

| 模型 | 最佳验证轮 | 独立测试准确率 | 测试交叉熵 | 错误样本数 |
| --- | ---: | ---: | ---: | ---: |
| MLP | 3 | 96.67% | 0.1089548626 | 333 |
| CNN | 3 | 98.45% | 0.04921373167 | 155 |

对应实验 ID：MLP 为 `9fbe732245894df3be3a45ee980c63ff`，CNN 为 `550f1b22c64045f89696db036db3a2dc`。两次运行均使用 54,000 张训练图像、6,000 张验证图像和 10,000 张官方测试图像。数值是本机本次运行的记录，其他配置、软件版本和硬件可能得到不同结果，不承诺固定训练耗时。

混淆矩阵的**行是真实标签，列是预测标签**，单元格数量之和等于测试集数量。点击非对角单元格会按真实/预测类别筛选错例；对角线是正确分类，因此不会返回错误样本。错例均来自同一个最佳权重的真实测试预测，按错误预测的模型分数排序并分页展示。softmax 分数不代表经过校准的可靠性保证。

### 后台任务与本地保存

服务使用单个可取消的后台训练任务，CPU 线程数最多为 4；其他页面与状态接口仍可访问。离开训练页面或刷新浏览器不会取消任务，重新打开页面可以从服务端记录恢复显示。新的训练任务不会覆盖已有模型；同时提交第二个任务会得到冲突提示。

首次“准备 MNIST”会联网下载官方文件到 `data/`，后续复用本地缓存。实验记录保存在 `runs/mnist/<run_id>/`，包含 `run.json`、验证集最佳权重 `best.pt`，以及已完成评估的错例记录。`data/` 与 `runs/` 已加入 `.gitignore`，不会作为代码提交。

取消请求会在批次边界安全停止，保留已完成 epoch 的指标及已有最佳权重。服务重启时，未完成任务标记为 `interrupted`，完成的历史与权重仍可读取；**目前不自动续训中断任务，也不恢复 Adam 优化器状态**，可以用相同配置新建实验。只有完整训练与测试都完成的任务才展示测试报告，取消或中断的任务不会填充估算指标。

训练页面可导出曲线 CSV，评估页面可导出包含配置、历史和评估结果的 JSON，并下载最佳模型 `.pt`。权重文件包含 `state_dict`、配置、最佳 epoch、验证损失和标准化信息；服务加载自己保存的权重时使用 `torch.load(..., map_location="cpu", weights_only=True)`。第四期会直接发现这些已完成实验的最佳权重，也可通过下面的脚本导出独立部署模型包。当前不支持在浏览器中上传任意权重。

### 从同一输入比较 MLP 与 CNN

推理模型目录同时读取 `runs/mnist/` 中已完成训练的记录和 `models/manifest.json` 发布包，同一实验优先使用本地训练记录。默认选择每种架构创建时间最新的已完成实验；每份权重的最佳 epoch 来自该实验的最低验证损失，测试准确率不参与选模型。手写识别页显示所选权重的来源、最佳 epoch、验证损失、独立测试参考准确率和 SHA-256。可以只识别一个模型，也可以让两个模型对同一份处理后图像分别前向计算。

服务使用 CPU、`eval()` 和 `torch.inference_mode()`，严格加载已保存的模型结构与参数，并缓存已加载的权重。没有可用模型或权重校验失败时会明确报错，不会用随机参数代替。页面显示实际模型计算用时及请求总用时；首次请求还需加载 PyTorch 与权重。十类分数来自真实 logits 的 softmax，不能解释为识别可靠性保证，第三期的独立测试准确率也不是当前手写输入的正确概率。

### 画布与预处理

画布为 280×280 黑底白笔迹，支持 8–36 像素画笔、清空和最多 20 步撤销。一次笔画结束后才读取完整灰度矩阵，点击识别后发送推理请求；开始编辑、清空、撤销或切换模型会立即使旧预测失效，并中止旧请求，避免把旧结果当成当前输入的结果。

后端接收两种输入模式：

- `canvas`：从大于 16 的像素确定笔迹边界，裁剪后等比例缩放到最长边 20 像素，放入 28×28 黑底图，再按灰度质心平移居中；平移不会环绕边缘，空白或过浅输入会被拒绝。
- `mnist`：真实官方测试示例保留原始 28×28 像素，不再次裁剪缩放。示例一旦被书写、清空或撤销，就按 `canvas` 模式处理。

两种模式最后都执行 `pixel / 255` 和权重中保存的均值、标准差归一化，与第三期对应模型一致。页面展示后端实际使用的 28×28 图像、原始尺寸与平移量；示例保留官方测试索引和真实标签，便于核对结果。测试示例来自打包文件或本地 MNIST 缓存，不是人工绘制的替代样本。

浏览器真实调用 `/api`，由 Vite 代理到 `127.0.0.1:8000`，不是用预录的结果模拟计算。若计算服务没有启动，页面会提示请求错误。第一期接口为 `/api/health`、`/api/data`、`/api/linear`、`/api/neuron`、`/api/loss` 和 `/api/gradient`。

第二期新增接口：

| 路由 | 请求与结果 |
| --- | --- |
| `POST /api/graph` | 输入两个输入值、两个权重、偏置、标签、学习率；返回全部节点值、梯度、边局部导数、拓扑顺序及一次真实 SGD 更新预览 |
| `POST /api/xor/init` | 输入整数随机种子；返回初始参数和网络快照 |
| `POST /api/xor/inspect` | 输入参数、当前迭代数和观察样本索引；返回同一参数下的前向值、单样本梯度、全量梯度与网格 |
| `POST /api/xor/step` | 输入参数、迭代数、学习率、1–100 步和观察样本索引；返回最终快照、每一步更新后的真实指标，以及最后一步所用梯度与参数变化 |

XOR API 的 `accuracy` 范围为 `0–1`，界面转换为百分比。预测网格按行从 `y_min` 向 `y_max` 排列，每行从 `x_min` 向 `x_max` 排列。API 可接受的迭代上限是 `20000`，当前教学界面另外采用 `5000` 步上限。

第三期新增接口：

| 路由 | 请求与结果 |
| --- | --- |
| `GET /api/mnist/status` | PyTorch 环境、数据准备状态与当前后台任务 ID |
| `POST /api/mnist/prepare` | 后台准备/下载 MNIST，立即返回状态，页面随后轮询 |
| `POST /api/mnist/split` | 根据种子、验证比例和训练子集规模返回真实划分、类别统计与三集合样本 |
| `GET /api/mnist/runs` | 最新优先的持久化任务列表 |
| `POST /api/mnist/runs` | 提交配置并启动后台真实训练，立即返回任务记录 |
| `GET /api/mnist/runs/{id}` | 单个任务的状态、训练历史和已完成的独立测试结果 |
| `POST /api/mnist/runs/{id}/cancel` | 在批次边界安全取消指定任务 |
| `GET /api/mnist/runs/{id}/errors` | 分页读取错例，可用 `true_label` 和 `predicted_label` 筛选；`offset` 从 0 开始 |
| `GET /api/mnist/runs/{id}/checkpoint` | 下载验证损失最佳模型的 `.pt` 文件 |
| `GET /api/mnist/runs/{id}/report` | 返回该任务的 JSON 报告 |

第三期 API 中的准确率、precision、recall、F1 和模型分数均为 `0–1`，界面转换为百分比；损失来自真实计算。错误分页单次最多返回 48 个样本，当前页面每页展示 12 个。

第四期新增接口：

| 路由 | 请求与结果 |
| --- | --- |
| `GET /api/inference/models` | 返回可用 CPU 运行环境、已完成实验或发布包中的模型、架构、最佳 epoch、来源、指标与 SHA-256，以及每种架构的默认模型 ID |
| `GET /api/inference/examples?label=7` | `label` 为 0–9；返回真实官方测试图像的 28×28 像素、测试索引、标签及 `source: "mnist-test"`，没有本地样本时返回 404 |
| `POST /api/inference/predict` | 请求包含 1–2 个不重复的 `model_ids`、灰度矩阵 `pixels` 和 `mode: "canvas"` 或 `"mnist"`；返回实际预处理图像与元数据、各模型预测、十类分数、前三类排名及计算用时 |

`pixels` 必须为 0–255 的有限数值、矩形矩阵，长宽分别在 8–320 之间；`mnist` 模式要求严格 28×28。返回的 `probabilities`、`top_k[].score` 为 `0–1`，时间字段单位为毫秒。比较的模型必须使用相同标准化参数，否则服务要求分别识别。

后端默认允许 `localhost:5173` 与 `127.0.0.1:5173` 的跨域请求；可用逗号分隔的 `CORS_ORIGINS` 环境变量覆盖。通过 Vite 同源代理访问 `/api` 时不需要额外跨域设置。
